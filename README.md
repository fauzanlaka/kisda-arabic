# أَلْعَابُ اللُّغَةِ العَرَبِيَّةِ الاتِّصَالِيَّةِ

Mind maps and review games for the Communicative Arabic course (13 lessons), one of each per lesson.
Prepared by Ustaz Asyari, KISDA.

Live site: https://fauzanlaka.github.io/kisda-arabic/

- `index.html` is the home page with a link to each lesson.
- `hisah-NN/index.html` is the game for lesson NN.
- `hisah-NN/kharitah/index.html` is the mind map for lesson NN.
- `lessons.js` lists the lessons that already have a game (`READY`) and a mind map (`MAPS`). It is generated by `bina_laman.py` in the course folder, along with the `hisah-NN/` copies; the mind maps are built first by `bina_peta_minda.py`.
