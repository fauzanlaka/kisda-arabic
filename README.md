# أَلْعَابُ اللُّغَةِ العَرَبِيَّةِ الاتِّصَالِيَّةِ

Review games for the Communicative Arabic course (13 lessons), one game per lesson.
Prepared by Ustaz Asyari, KISDA.

Live site: https://fauzanlaka.github.io/kisda-arabic/

- `index.html` is the home page with a link to each lesson.
- `hisah-NN/index.html` is the game for lesson NN.
- `lessons.js` lists the lessons that already have a game. It is generated by `bina_laman.py` in the course folder, along with the `hisah-NN/` copies.
